# Dreamwave Radio - iPhoneとiPadのための睡眠サウンド・ホワイトノイズ・環境音ミキサー

[![対応](https://img.shields.io/badge/対応-iOS_17+-lightgrey?logo=apple)](https://www.apple.com/jp/ios/)
[![Swift](https://img.shields.io/badge/Swift-5.0-orange?logo=swift&logoColor=white)](https://swift.org)
[![プライバシー](https://img.shields.io/badge/収集データ-なし-brightgreen)](privacy_policy.md)
[![GitHub stars](https://img.shields.io/github/stars/aloth/dreamwave-radio?style=social)](https://github.com/aloth/dreamwave-radio/stargazers)

**環境音を自分好みに重ねて、タイマーで眠りに落ちる。アカウントなし、追跡なし、何も端末から出ません。**

[![App Storeでダウンロード](https://img.shields.io/badge/App_Storeで-ダウンロード-0d96f6?style=for-the-badge&logo=apple&logoColor=white)](https://apps.apple.com/app/id6790789119)

**買い切り 4.99 ドル。** サブスクなし、広告なし、アプリ内課金なし。

たいていの睡眠アプリは、決まったプレイリストと毎月の請求書を渡してきます。Dreamwave Radio が渡すのはミキシングデスクです。焚き火の上に雨を重ね、夜行列車の下に扇風機を敷き、それぞれの音量を別々に決めて、本当に眠りたい部屋の響きになるまで調整できます。

## ✨ 何が違うのか

### 🎚️ 同時に3つまで重ねる

プレイリストではなくミックスです。最大3つの局を固定して、それぞれの音量を個別に調整できます。遠雷の上にテントの雨。焚き火の下に夜風。組み合わせこそが本質です。

### 🔊 決して繰り返さない音

たいていの睡眠アプリは録音をループ再生するので、午前3時に継ぎ目が聞こえてしまいます。夜風は決して重ならない3つの周期で吹きます。遠くの雨は一粒ごとに違う場所へ落ちます。猫のゴロゴロは、猫がそうするように時々止まります。アプリは再生しながらこれらの音をつくっているので、聞こえる継ぎ目がありません。

録音された音も継ぎ目なくつながるように仕上げてあるので、長い夜がひと続きの音になり、何度も最初から始まるトラックにはなりません。

### 🗣️ 話しかけるだけ

「Dreamwave Radio で雨を再生して」「スリープタイマーを設定して」「あと15分ちょうだい」。Siri がサウンドを再生し、ミックスに追加し、タイマーを延ばします。アプリが画面に現れることは一度もありません。Siri でできることはすべてショートカットにもなるので、就寝前の習慣に組み込めます。

### ⏱️ フェードアウトするタイマー

いつもの夜のためのプリセット、または1分から120分まで自由に指定できます。ミックスは急に止まらず静かに消えていくので、タイマーが去り際にあなたを起こすことはありません。動作中はロック画面と Dynamic Island に表示され、ひと目で残り時間がわかります。

### 🌙 ナイトモード

暗い寝室のために画面全体を暗くするので、タイマーを確認するのに顔へ懐中電灯を向けるようなことにはなりません。

### 📱 iPhone でも iPad でも

1つのアプリを両方のために。iPhone では暗闇でも片手で届きます。iPad ではサウンドライブラリが全画面で開き、ライブラリ全体が一度に目の前に並びます。

### 🔒 アカウントなし、通信なし、データなし

サインアップも、解析も、サーバーもありません。送る先がないので、アプリはデータを集めません。[プライバシーポリシー](privacy_policy.md)をご覧ください。

**やすらぎ** - 胎内 · 扇風機 · 車の走行 · ゆるやかな流れ · 猫のゴロゴロ · 機内 · シーッ
