# Dreamwave Radio - iPhoneとiPadのための睡眠サウンド・ホワイトノイズ・環境音ミキサー

[![対応](https://img.shields.io/badge/対応-iOS_17+-lightgrey?logo=apple)](https://www.apple.com/jp/ios/)
[![Swift](https://img.shields.io/badge/Swift-5.0-orange?logo=swift&logoColor=white)](https://swift.org)
[![プライバシー](https://img.shields.io/badge/収集データ-なし-brightgreen)](privacy_policy.md)

**環境音を自分好みに重ねて、タイマーで眠りに落ちる。アカウントなし、追跡なし、何も端末から出ません。**

[![App Storeでダウンロード](https://img.shields.io/badge/App_Storeで-ダウンロード-0d96f6?style=for-the-badge&logo=apple&logoColor=white)](https://apps.apple.com/app/id6790789119)

**一度買えば、ずっとあなたのもの。** サブスクなし、広告なし、アプリ内課金なし。

たいていの睡眠アプリは、決まったプレイリストと毎月の請求書を渡してきます。Dreamwave Radio が渡すのはミキシングデスクです。焚き火の上に雨を重ね、夜行列車の下に扇風機を敷き、それぞれの音量を別々に決めて、本当に眠りたい部屋の響きになるまで調整できます。

---

## 🆕 2.0 の新機能

- **新しいデザイン：** すべてのミックスに専用のカバーがつきました。再生中のミックスは画面の上部に表示され、ミックスの一覧はカバーのグリッドで開き、サウンドの後ろではカバーがやさしく光ります。
- **ドリームスケープ：** 夜と集中のための3つの新しいサウンド、ネオンの地平線、真夜中のドローン、真空管のハム。さらに、すぐ使える新しいミックス「ネオンの海岸」と「真夜中の雨」の2つを追加。
- **日本語で Siri：** Siri に日本語で話しかけられるようになりました。たとえば「Dreamwaveでテントの雨を再生」や「Dreamwaveでもう少し延長して」。
- **新しいアイコン。** ホーム画面ではアプリ名がシンプルに「Dreamwave」になりました。
- **ミックスはそのまま：** 保存したミックスはそのまま残ります。それぞれに自分の写真をカバーとして設定することもできます。新しいミックスは空きがある限り追加されます。

## ✨ 何が違うのか

### 🎚️ 同時に3つまで重ねる

プレイリストではなくミックスです。最大3つの局を固定して、それぞれの音量を個別に調整できます。遠雷の上にテントの雨。焚き火の下に夜風。組み合わせこそが本質です。

### 💾 ワンタップでミックス

すぐ使える5つのミックス「雨の夜」「集中」「やさしい眠り」「ネオンの海岸」「真夜中の雨」から始められます。自分のミックスも保存できます。最大3つのサウンドを固定して音量を整え、再生ボタンの横のブックマークをタップするだけ。すべてのミックスに専用のカバーがあり、保存したミックスには自分の写真をカバーとして設定することもできます。ミックスの一覧はカバーのグリッドで開き、音量ごとワンタップで呼び戻せます。

### 📚 集中と勉強にも

同じサウンドは昼間にも役立ちます。窓を打つ雨の下にブラウンノイズを流せば、オフィスやカフェ、家の中の話し声をやわらげ、集中や勉強、読書に向き合えます。

### 🔊 ひと晩じゅう静かに

プツッという音も、つなぎ目の違和感もありません。必要なだけ、サウンドが均一に流れ続けるので、長い夜もひとつの穏やかな音のまま。何度も最初から始まるトラックとは違います。「夜風」はゆっくりと強まっては弱まり、「遠くの雨」では雨粒が毎回ちがう場所に落ち、「猫のゴロゴロ」は猫のようにふと間をおきます。

### 🗣️ 話しかけるだけ

「Dreamwaveで雨音を再生」「Dreamwaveでもう少し延長して」Siri とショートカットで、明るい画面を見なくてもサウンドを再生できます。Siri には日本語で話しかけられます。Siri でできることはすべてショートカットにもなるので、就寝前の習慣に組み込めます。

### ⏱️ フェードアウトするタイマー

いつもの夜のためのプリセット、または1分から120分まで自由に指定できます。ミックスは急に止まらず静かに消えていくので、タイマーが去り際にあなたを起こすことはありません。動作中はロック画面と Dynamic Island に表示され、ひと目で残り時間がわかります。

### 🌙 ナイトモード

暗い寝室のために画面全体を暗くするので、タイマーを確認するのに顔へ懐中電灯を向けるようなことにはなりません。

### 📱 iPhone でも iPad でも

1つのアプリを両方のために。iPhone では暗闇でも片手で届きます。iPad ではサウンドライブラリが全画面で開き、ライブラリ全体が一度に目の前に並びます。

### 🎧 ポッドキャストと一緒に

設定で「他のオーディオと同時に再生」をオンにすると、ポッドキャストやオーディオブックを止めずに、その下でミックスが静かに流れます。初期設定はオフです。

### 🔒 アカウントなし、通信なし、データなし

サインアップも、解析も、サーバーもなく、マイクへのアクセスを求めることもありません。ミックスのカバーに選んだ写真は、あなたのデバイスの中にとどまります。送る先がないので、アプリはデータを集めません。[プライバシーポリシー](privacy_policy.md)をご覧ください。

## ❓ よくある質問

**ホーム画面でアプリ名が「Dreamwave」になっているのはなぜ？**

2.0 から、アイコンの下の名前はシンプルに「Dreamwave」になりました。アプリの名前は App Store でもアプリ内でも引き続き Dreamwave Radio で、Siri はどちらの名前でも理解します。

**アップデート後も保存したミックスは残りますか？**

はい。保存したミックスはそのまま残ります。すぐ使える新しいミックス「ネオンの海岸」と「真夜中の雨」は空きがある限り追加され、どのミックスにも自分の写真をカバーとして設定できます。

**すでにアプリを持っている場合、2.0 は有料ですか？**

いいえ。2.0 は Dreamwave Radio をお持ちのすべての方への無料アップデートです。一度買えば、ずっと使えます。今あるサウンドも、これから増えるサウンドもすべて含まれています。

**写真へのアクセスは必要ですか？**

いいえ。ミックスのカバーに写真を選ぶと、システムの写真ピッカーが選んだ1枚だけをアプリに渡します。写真ライブラリにアクセスすることはありません。写真はあなたのデバイスの中にとどまり、アップロードされることはありません。

**オフラインでも使えますか？**

はい、完全に使えます。すべてのサウンドはデバイス上で再生されるので、機内モードでも、電車の中でも、Wi-Fi のないホテルでも使えます。

**耳鳴りに役立ちますか？**

耳鳴りを気になりにくくするために、やさしいノイズを使う人はたくさんいます。Dreamwave Radio には七種類のノイズカラーがあるので、自分に合う音を探せます。ただし医療機器ではなく、耳鳴りを治療するものではありません。耳鳴りがよく起きる、または最近始まった場合は、医師に相談してください。
